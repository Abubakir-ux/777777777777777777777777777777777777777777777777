# Kim bu? — hazil sayt

## O'rnatish
1. Python 3.9+ o'rnating.
2. Kutubxonalar:
   pip install flask numpy face_recognition
   (face_recognition dlib'ni o'rnatadi; Windows'da CMake va Visual Studio Build Tools kerak bo'lishi mumkin.
   Osonroq yo'l: Linux yoki Google Colab / Termux emas, oddiy kompyuter yoki Replit.)

## Ishga tushirish
   ADMIN_PAROL=mening_parolim python app.py
   (Windows PowerShell: $env:ADMIN_PAROL="mening_parolim"; python app.py)

Brauzerda oching: http://localhost:5000
Telefondan: kompyuter bilan bir xil Wi-Fi'da http://KOMPYUTER_IP:5000

## Ishlatish
1. /admin ga kiring, parolni yozing.
2. Do'stingizning ismi, hazil ma'lumotlari va rasmini qo'shing.
3. Bosh sahifada rasm yuklang — mos odam topilsa, ma'lumot chiqadi.

## Eslatma
- Rasm tiniq va yuz aniq ko'ringan bo'lsin.
- Saytni internetga ochiq qo'ymang, faqat hazil uchun o'zingiz ishlating.
- Do'stingizga hazildan keyin ayting va xohlasa rasmini bazadan o'chiring.
